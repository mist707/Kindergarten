# Детский сад — учёт детей, групп и воспитателей

Курсовой проект по дисциплине «Программная инженерия» (тема № 26 «Приложение для детского сада»)[cite: 1].

Настольное приложение на **C# (Windows Forms, .NET Framework)** для автоматизации учёта воспитанников, групп и воспитателей детского сада. Программа работает локально на одном ПК, не требует установки СУБД и хранит данные в текстовых файлах в кодировке UTF-8[cite: 1].

## Основные возможности

* **Авторизация:** вход по логину и паролю (`admin` / `12345` по умолчанию, данные берутся из `admin.txt`)[cite: 1].
* **Учёт детей:**
  * просмотр списка воспитанников с автоматическим расчётом возраста по дате рождения и отображением данных родителей[cite: 1];
  * добавление, редактирование и удаление записей[cite: 1];
  * быстрый поиск по части ФИО и фильтрация по группе[cite: 1];
  * проверки обязательных полей, возраста ребёнка (от 1 до 7 лет) и наличия свободных мест в выбранной группе[cite: 1].
* **Учёт групп:**
  * просмотр списка групп, возрастной категории, назначенного воспитателя и текущей наполняемости (`детей / мест`)[cite: 1];
  * добавление, изменение и удаление групп с проверкой уникальности названия и запретом удаления группы, в которой есть дети[cite: 1].
* **Учёт воспитателей:**
  * ведение списка сотрудников (ФИО, телефон, стаж, закреплённая группа)[cite: 1];
  * контроль правила «один воспитатель — одна группа» и запрет удаления воспитателя, за которым закреплена группа[cite: 1].
* **Отчёт по наполняемости групп:** расчёт количества детей, свободных мест и процента заполненности по каждой группе и по всему учреждению[cite: 1].

## Хранение данных

Данные сохраняются автоматически в текстовые файлы в папке с исполняемым файлом (разделитель полей — `;`, кодировка `UTF-8`)[cite: 1, 2]:
* `children.txt` — воспитанники;
* `groups.txt` — группы;
* `teachers.txt` — воспитатели;
* `admin.txt` — логин и пароль для входа[cite: 1].

При первом запуске, если файлы данных отсутствуют, приложение автоматически создаёт их и заполняет демонстрационными записями[cite: 1, 2].

## Структура проекта

* `Program.cs` — точка входа, загрузка данных и запуск формы входа[cite: 1].
* `Child.cs`, `Group.cs`, `Teacher.cs` — модели сущностей и сериализация/десериализация строк файлов[cite: 1].
* `DataStorage.cs` — работа с текстовыми файлами, поиск, подсчёт наполняемости и проверка логина/пароля[cite: 1].
* `Form1.cs` — окно входа в систему[cite: 1].
* `Form2.cs` — главное окно с вкладками «Дети», «Группы», «Воспитатели» и «Отчёт по группам»[cite: 1].
* `Form3.cs` — окно добавления и редактирования записи о ребёнке[cite: 1].
* `Form4.cs` — окно добавления и редактирования группы[cite: 1].
* `Form5.cs` — окно добавления и редактирования воспитателя[cite: 1].

## Запуск проекта

1. Откройте файл решения `Kindergarten.sln` в **Microsoft Visual Studio** (требуется установленный .NET Framework 4.7.2)[cite: 1, 2].
2. Соберите и запустите проект (`F5` или `Ctrl + F5`).
3. Для входа используйте логин `admin` и пароль `12345`[cite: 1].
